
# Prototipação Inicial - HelpDesk Pro

Esta pasta reúne a documentação dos wireframes iniciais das telas do sistema, desenvolvidos no Figma para validar o fluxo de navegação antes da implementação completa do front-end.

## Telas Planejadas
1. **Tela de Login (`Desktop - 1`):** Autenticação por e-mail e senha com botão de acesso.
2. **Painel / Lista de Chamados (`Frame 5`):** Visualização dos chamados e acesso à abertura de novos tickets.
3. **Cadastro e Detalhes do Chamado (`Frame 6`):** Formulário/área para criação ou acompanhamento e comentários do chamado.
